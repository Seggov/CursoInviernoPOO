# Revisión realizada

## Organización

- Se separó el material en 12 proyectos Java/Eclipse independientes.
- Se ordenaron de menor a mayor dificultad.
- Cada proyecto incluye un `README.md` con explicación breve y ejercicio propuesto.
- Se normalizaron paquetes para que coincidan con la estructura de carpetas.

## Apuntes nuevos

- Referencias.
- Herencia.
- Clases abstractas.
- Interfaces.
- Polimorfismo.
- Proyecto integrador de figuras.

## Mejoras sobre los ejemplos anteriores

- Objetos: encapsulación básica, getters y método que modifica el estado.
- Arrays: suma y promedio.
- Lista con array: comentarios simplificados y validaciones.
- Matrices: suma total.
- LinkedList: operaciones de inicio/final y tamaño.
- Nodos: lista doble ordenada, búsqueda, inversión y visualización de conexiones.
- Herencia: ejemplo de Mascota/Perro/Gato y atenciones.
- Figuras: se conserva `verificarSiCabe(...)` como pendiente porque necesita una regla geométrica concreta.

## Verificación

Todos los proyectos fueron compilados de forma independiente con `javac` y sus ejemplos principales fueron ejecutados correctamente.
