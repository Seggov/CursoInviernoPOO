# 06 - LinkedList de Java

## Idea simple

`LinkedList` es una estructura ya implementada por Java. Puede crecer y disminuir sin que tú manejes manualmente un array.

```java
LinkedList<String> nombres = new LinkedList<>();
```

## Métodos usados

- `add()` agrega.
- `addFirst()` agrega al inicio.
- `addLast()` agrega al final.
- `get()` obtiene por posición.
- `remove()` elimina.
- `size()` entrega cantidad.
