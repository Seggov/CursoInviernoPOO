# 02 - Arrays

## Idea simple

Un array guarda varios valores **del mismo tipo** y tiene un tamaño fijo.

```java
int[] numeros = new int[5];
```

Sus posiciones comienzan en `0`.

## Conceptos del ejemplo

- Crear arrays de `int` y `String`.
- Recorrerlos con `for`.
- Llenarlos con valores aleatorios.
- Mostrar con `Arrays.toString()`.
- Calcular suma y promedio.

## Ejercicio

Crea un método `buscarMayor(int[] lista)` que retorne el número más grande.
