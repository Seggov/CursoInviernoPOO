# Apuntes ordenados — Curso de Invierno POO

Esta carpeta es una **vista limpia y ordenada para estudiar**. El proyecto original sigue en `src/` y no se eliminaron tus prácticas, tareas ni versiones históricas.

## Orden recomendado

1. **Objetos** — crear instancias, atributos, constructor y métodos.
2. **Arrays y listas** — arreglos, inserción, eliminación y búsqueda.
3. **Matrices** — arreglos bidimensionales y recorridos con dos `for`.
4. **LinkedList de Java** — uso básico de `LinkedList`.
5. **Nodos y referencias** — primero la versión mínima y luego la lista doble completa.
6. **Herencia** — clase padre, clases hijas, `super`, sobrescritura y relación con `Atencion`.

## Repeticiones que no copié aquí

Había varias implementaciones de `Nodo`, `Persona` y listas dobles en:

- `src/winter/`
- `src/PracticandAndo/`
- `src/Tareas/Nodos/`
- `src/Apuntes/Nodos/`
- `src/Apuntes/MinimoNodos/`

No las borré del proyecto porque algunas son ejercicios o versiones de distinta dificultad. En esta carpeta dejé solo dos versiones útiles para estudiar nodos:

- **01_Version_Minima**: entender `sig`, `prev` y el recorrido.
- **02_Version_Completa**: insertar, buscar, ordenar, obtener por índice, vaciar e invertir.

Así se evita estudiar cinco veces prácticamente la misma base.
